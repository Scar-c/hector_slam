# 四项修复的核心消融及向原版迁移

目标：区分保留XYZ、共享姿态、高度/体素过滤、射线原点修正的作用，并实测对官方launch原版行为只应用核心过滤能否消除前30秒偏移。

## 结论

1. **官方launch原版行为：只加0.025m体素过滤就能把本段偏移降到厘米量级。** 真实1倍速前30秒，evo平移APE RMSE从0.613311m降到0.044683m，最大从0.810994m降到0.123422m。地图分辨率0.05m、两层、2048格、更新0.4m/0.06rad、5帧队列、原高度[-1,1]、固定外参、原距离过滤均不变；无desk、IMU姿态、运动先验或轨迹平滑。Hector核心21文件保持上游原样，仅ROS2输入适配增加可选VoxelFilter。
2. **我们的旧desk输入链：过滤是核心组合，但单独加体素不足以修复。** 将第三项拆成高度范围和体素两个开关，与其他三项组成5个开关，共32组。所有达到厘米量级的组合都开启较宽高度[-0.8,2]和0.025m体素过滤；还需保留XYZ或共享姿态等几何配合。不能从只撤回某一项的结果推出它在所有有效组合中必需。
3. **共享姿态和射线原点不是这段米级偏移消除的必要条件。** 完整方案分别撤回它们仍为约0.0464m和0.0373m RMSE。保留XYZ的作用存在交互：完整方案撤回XYZ为0.9327m，但保留旧二维重采样、共享姿态+新高度+体素、旧射线原点的另一组合为0.0246m。因此不能把保留XYZ称为唯一必要核心。

本结论只针对本包前30秒的控制变量实验，不宣称所有场景都由单一原因漂移，也不据此确认上游某一行代码是唯一bug。参考为Cartographer关闭回环的在线轨迹，不是独立真值；无轨迹对齐/尺度拟合/时间偏移拟合。

## 1倍速迁移验证

`live_official_voxel/`：同一次严格1倍速回放，将原始扫描分发给两套独立原样Hector核心；只有体素开关不同。每套1123扫描/1123位姿，TF丢帧0，5922条IMU只记录不使用，进程已退出。对应离线输出与在线XY逐帧最大差小于5.1e-14m。

原版输入本来没有我们新增的“deskXYZ转回二维扫描”步骤，而且真实射线原点已经由TF提供；在固定外参这一组，所有点的相对高度为0，改变高度范围不改变点集。原版这里直接加体素就有效，不等于给我们旧desk链单独加体素也有效。

## 32组离线设计

固定第一次失败运行记录的扫描/去畸变XYZ/IMU，固定地图0.05m、3层、更新0.2m/0.08rad。不开ROS加速回放。依次切换：

- A：保留XYZ / 使用旧二维重采样LaserScan。
- B：复用desk参考姿态 / 原内部0.5秒姿态滤波。
- C：高度[-0.8,2] / [-1,1]。
- D：0.025m三维体素 / 不过滤。
- E：真实雷达射线原点 / 旧base原点。

32组是固定已记录desk输入的因果消融；没有在每组中重新闭环估计历史desk平移。用于区分过滤/几何处理作用。最终完整方案和本次原版体素迁移另有真实1倍速验证。

在做消融前，离线工具复现了旧链和完整链已有轨迹，逐帧XY差为0；原版离线基线也复现真实官方launch轨迹。详见offline_outputs/metrics.json中的validation。

| 组合 | 位移差RMSE[m] |
|---|---:|
| 旧链，全部开关旧值 | 1.272969 |
| 完整修复 A+B+C+D+E | 0.034874 |
| 完整方案撤回XYZ（其余新值） | 0.932717 |
| 完整方案撤回共享姿态 | 0.046439 |
| 完整方案撤回新高度 | 1.105991 |
| 完整方案撤回体素 | 1.037088 |
| 完整方案撤回射线原点修正 | 0.037302 |
| 仅新高度+体素，其余旧值 | 0.991289 |
| 共享姿态+新高度+体素，其余旧值 | 0.024637 |
| XYZ+新高度+体素，其余旧值 | 0.046190 |

这些是同一固定输入的参考插值指标，和在线evo最近时刻关联指标分开列出，避免混用。

## 为什么体素过滤有效

Hector GN目标按点累加残差和Hessian，每个点分别贡献。角度均匀采样不等于空间均匀采样，靠近或密集的表面可能贡献很多相近点。体素过滤在每个0.025m空间格中保留一个原始点，改变参与匹配的点集和隐含空间权重。实测6–8秒匹配点数中位数由995降到720.5。它没有对输出位姿做低通或限幅，也没有改变地图更新阈值。

“只改输入体素即可消除本段大偏移”的因果改善已通过对照和1倍速验证；具体哪个表面/哪组点如何拉偏每一步GN，尚未做逐点归因，因此不把空间重复计权描述为已证明的唯一微观机制。

## 复现

```bash

```

离线执行：先编译本目录，然后 `python3 run_probes.py`。完整32组输出及原始扫描/XYZ/IMU输入也保存到results，路径以脚本中记录的本机工作区为准。
